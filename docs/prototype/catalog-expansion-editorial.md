## Research papers

Four arXiv discovery cohorts each contain the first 800 visible results, ordered by newest announcement: computer vision, reinforcement learning, natural language processing, and robotics. These are search-result cohorts, not expert-verified topic classifications. Titles, author lists, source categories, submission text, comments, canonical abstract URLs, and brief abstract excerpts are preserved. Unusually long author lists are capped at the catalog schema limit and explicitly marked `creatorTruncated`.

The next query rendered **`Rate exceeded.`** after a navigation timeout. Collection stopped immediately. The resulting source status is `partial`; no alternate identity, proxy, endpoint, or retry was used to bypass the limit. The collector now refuses to run while the rate-limit evidence marker is present. Planned queries which were never successfully retrieved do not produce collections or items.

## Files and reproducibility

Everything for this expansion lives in `demo/catalog-crawl/expansion/editorial/`:

- `arxiv-expanded.json` and `standard-ebooks-expanded.json`: normalized import batches.
- `evidence/*.json`: compact page-level DOM records, including listing URL, capture time, pagination, and individual cards.
- `evidence/*-snapshot.txt`: actual browser accessibility snapshots.
- `evidence/arxiv-rate-limit.txt`: the observed stop condition.
- `evidence/standard-ebooks-last-page.png`: screenshot of the final book listing.
- `arxiv-report.json` and `standard-ebooks-report.json`: page counts, timestamps, completed scope, and stop status.
- `quality-report.json`: machine-checked schema, uniqueness, evidence coverage, and per-collection counts.
- `collect-arxiv.mjs`, `collect-books.mjs`: bounded, sequential collectors which reuse saved evidence when resuming.
- `audit.mjs`: verifies every normalized item's exact metadata against saved DOM evidence, checks identities/memberships, and validates the production catalog schema.

From the `demo` directory:

```sh
# Audit the saved evidence and normalized batches; no browser/network required.
node --import tsx catalog-crawl/expansion/editorial/audit.mjs

# Import only normalized batch files, not reports or evidence.
npm run catalog:import -- catalog-crawl/expansion/editorial/arxiv-expanded.json catalog-crawl/expansion/editorial/standard-ebooks-expanded.json

# Rebuild the book batch from saved evidence, or collect a missing subsequent page.
node catalog-crawl/expansion/editorial/collect-books.mjs
```

The production schema audit passed for all **4,442 unique expansion records**. Every normalized record matches saved browser metadata exactly; all extraction labels are `browser-dom`. No application code, private preferences, or live model state was changed by these collectors. Query relevance and metadata do not imply that Jev has read the full papers or analyzed cover images.
